# Step 3

## Goal

Support pre-release semvers.

## Changes

The following semvers will be supported:
- `<alpha> ::= <core>-alpha | <core>-alpha.<int>`
- `<beta> ::= <core>-beta | <core>-beta.<int>`
- `<rc> ::= <core>-rc | <core>-rc.<int>`

Pre-releases need to be specified exactly the same to be compatible.
